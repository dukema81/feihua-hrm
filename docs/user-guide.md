# 飞花HRM系统项目说明与操作手册

**版本**：V1.0 ｜ **适用对象**：HR 专员 / 部门经理 / 薪酬专员 / 招聘专员 / 普通员工 / 系统管理员

---

## 1. 系统简介

飞花HRM是零依赖人力资源管理系统：Python 标准库即可运行（无需安装任何第三方包），浏览器直接访问。覆盖员工全生命周期（建档→转正→离职）、考勤假期、薪资核算、招聘、绩效、培训与合同风险。

## 2. 启动与登录

```bash
python backend/server.py               # 默认 127.0.0.1:8025
FEIHUA_PORT=9000 python backend/server.py   # 自定义端口
```

- 数据库：`backend/data/feihua.db`（可用 `FEIHUA_DB` 指定）；首次启动自动建库并灌入演示数据；
- 访问 `http://127.0.0.1:8025/`，未登录自动跳转登录页。

## 3. 界面骨架

顶栏（品牌/版本/退出）→ 主菜单（组织人事/考勤假期/薪酬绩效/招聘培训/基础/系统）→ 左侧导航（带待办徽标）→ 工作区 → 右侧信息栏（待办与准则）→ 底部状态条（操作提示与消息）。

## 4. 逐页操作说明

### 4.1 HR 驾驶舱
在职人数、本月出勤率、待审批、在招职位、最近薪资批次、合同风险六张 KPI 卡；近 30 天考勤趋势、部门编制分布、绩效等级分布。红色徽标提示待办入口。

### 4.2 员工档案
按状态筛选（试用期/已转正/离职中/已离职）；点击行打开档案详情：假期余额、最近请假、绩效趋势。
- **转正**：试用期员工详情 → 「办理转正」→ 填转正评估（必填；试用期绩效须 ≥60 分）；
- **离职**：已转正 → 「发起离职」→ 状态变离职中 → 「确认交接完成」→ 填交接说明办理离职；
- **建档**：「新建员工」填工号/姓名/部门/入职日期/基本工资，系统自动按工龄折算年假额度。

### 4.3 组织架构
部门列表含编制达成率进度条；管理员可新建部门。

### 4.4 合同风险
临期（≤60 天）金色、已到期红色分档展示；点击风险行 → 填新到期日与合同类型 → 一键续签（旧合同置已续签，生成新合同）。

### 4.5 考勤管理
月度出勤汇总（出勤率/迟到分钟/异常/累计工时）；「打卡」按工号上/下班打卡（午休 1 小时自动扣减、宽限 15 分钟）；管理员可「手工调整」补卡或标记请假/出差。

### 4.6 请假审批
「提交请假」选类型与起止（年假/调休校验余额，时间重叠拦截）；审批人「批准」（自动扣额度）或「驳回」；已批准单可「销假」（额度返还）。事假不占额度。

### 4.7 加班管理
提交加班选类型（工作日 1.5 倍 / 周末 2 倍 / 节假日 3 倍）；单次超月度 36 小时上限被拦截；审批通过后计入工资核算。

### 4.8 薪资核算
「新建批次」选月份 → 「核算」按口径生成全员工资条（绩效奖金 = 基本工资×20%×最近绩效分；加班费按已批准单；三险一金按基数 4 千~2.4 万封顶；个税七档累进；缺勤按日薪扣减）→ 核对工资条弹层 → 「发放」。工资条数量少于在职人数会被闸口拦截。

### 4.9 绩效考核
新建考核周期 → 点击员工行录四维分（数量30%/质量40%/协作15%/纪律15%，总分与等级自动计算）→ 「归档发布」后锁定。空周期不能归档。

### 4.10 招聘管道
「职位」页签：发布/关闭职位；「候选人」页签：漏斗概览（初筛→面试→Offer→入职）。点击候选人：安排面试（自动转面试中）→ 录入结果 → 「发 Offer」（须有面试通过记录 + 核定薪酬）→ 「确认入职」。

### 4.11 培训管理
新建培训（主题/讲师/日期/学时/名额）；详情弹层报名（满员拦截、防重复）与录成绩（≥60 已完成，<60 缺席）。

### 4.12 报表中心
在职/离职率/出勤率 KPI、部门与职级分布；CSV 导出：考勤明细、请假记录、工资条（需薪资权限；UTF-8 BOM，Excel 直接打开）。

### 4.13 集成中心
API Key：生成（fhk_ 前缀，明文仅显示一次，read 只读 / write 读写）与吊销；Webhook：新建回调 + secret、发送 test.ping 验证投递链路；投递记录查看签名投递状态；增量同步试拉。

### 4.14 系统设置
业务规则（管理员改值即时生效）；账号与权限（8 角色 × 11 权限矩阵）；系统信息与对接说明。

### 4.15 操作日志
全部写操作审计：登录、建档、状态变更、审批、算薪、评分、规则修改、集成配置。

## 5. 角色场景演练

**HR 专员的一天**：驾驶舱看待审批 → 请假页批准 2 单 → 考勤页给缺卡员工补卡 → 招聘页给 Offer 候选人确认入职 → 员工页给试用期员工办转正。

**薪酬专员月末**：新建当月批次 → 核算 → 打开工资条弹层抽查勾稽（实发=应发−社保−公积金−个税−缺勤）→ 确认发放 → 导出工资条 CSV 归档。

**部门经理季度**：绩效页为本部门员工录四维分 → 归档发布 → 合同页关注临期成员 → 招聘页推进本部门职位。

**普通员工自助**：考勤页打卡 → 请假页提交事假 → 档案页查看自己假期余额与绩效趋势。

## 6. 离线 DEMO

`demo/feihua-hrm-demo.html` 单文件 305KB：双击用浏览器打开即可，无需服务与网络。内置确定性演示数据（8 部门 / 22 员工 / 30 天考勤 / 招聘漏斗 / 薪资批次），新建员工、提交请假、批次核算、API Key 生成等写操作在浏览器内存中按与后端一致的口径真实计算。数据存于 sessionStorage（键 `fh_hrm_demo`），关闭标签页前可刷新恢复。

## 7. 常见问题

| 问题 | 处理 |
| --- | --- |
| 转正按钮点了报「绩效得分低于 60」 | 先到绩效考核页给该员工录入 ≥60 的评分 |
| 请假提交报「余额不足」 | 年假/调休按额度校验；改提事假（不占额度、按无薪扣款） |
| 打卡报「今日已完成上下班打卡」 | 当日已双卡；如需修正由管理员在考勤页手工调整 |
| 核算按钮灰色/不存在 | 批次不是草稿状态；已核算批次直接点「发放」 |
| 工资条看不到 | 薪资仅 pay.read 权限角色可见（admin/hrd/zhangx/shenj） |
| 导出 CSV 中文乱码 | 文件已带 UTF-8 BOM，若仍乱码用 WPS/Excel「数据-自文本」导入 |
| Webhook 投递显示 failed | DEMO/本机环境不外发回调属预期；生产填可公网访问的地址 |
| 忘记 admin 密码 | 删除 backend/data/feihua.db 后重启自动重建演示库 |

## 8. 运维与备份

- **备份**：定期复制 `backend/data/feihua.db`（WAL 模式下建议用 `sqlite3 feihua.db ".backup backup.db"`）；
- **重置演示数据**：停止服务 → 删除 `backend/data/feihua.db*` → 重启；
- **健康检查**：`GET /api/health` 免鉴权，可用于守护进程探活；
- **生产部署**：前置 Nginx 反代（静态资源 + /api 转发 8025），HTTPS 必开；日志接 ELK 可解析 logs 表。
