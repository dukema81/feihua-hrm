## 2. 测试策略与环境

- **分层**：内核纯函数（不依赖服务）→ 接口（独立临时库 + 独立端口 8955）→ E2E（浏览器 8956）→ 冒烟（对 8025 开发服务）；
- **环境**：Windows / Python 3.13 / SQLite WAL；E2E 用 Playwright（Chromium/Edge/Chrome 回退链）；
- **数据**：种子数据确定性生成（随机种子 20261021），22 员工 / 8 部门 / 30 天考勤 / 请假 8 / 加班 6 / 候选 8 / 培训 4；
- **门禁**：`python scripts/run_tests.py` 三层串行，任一失败即退出非零。

## 3. 关键验证点

| 验证点 | 断言 |
| --- | --- |
| 转正闸口 | 缺评估 400；绩效 <60 拦截；通过后 regular_date 自动写入 |
| 离职闸口 | 未进「离职中」直接办离职被拦；交接未确认被拦 |
| 请假闸口 | 年假超余额拦截；时间重叠拦截；批准扣额度、销假返还 |
| 加班上限 | 月度已批累计 + 新申请 > 36h 拦截 |
| 薪资闸口 | 草稿直发拦截「必须先完成核算」；核算条数=在职人数；net 勾稽恒等式 |
| 个税 | 起征下零税；2 千应税 3% 档；1.5 万应税 20% 档速算扣除；9.5 万应税 45% 档 |
| 社保 | 基数下限 4000 托底、上限 24000 封顶；个人 10.5% + 公积金 12% |
| 权限 | 员工/审计/薪酬/HR 四角色越权全部 403；错误密码 401 |
| 幂等 | 同 Idempotency-Key 两次提交返回同一请假单号 |
| 集成 | fhk_ Key GET 通、POST 403、吊销后 401；test.ping 投递记录；增量同步返回员工变更 |

## 4. 缺陷台账（发现 → 修复 → 回归）

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 所有响应 500 latin-1 编码错误 | Server 响应头含中文品牌「飞花HRM」 | server_version 改 ASCII "FeiHua-HRM" |
| 2 | 驾驶舱 500 | attTrend 查询参数漏元组逗号，10 字符串被拆成 10 个绑定 | 补 `(str,)` 元组 |
| 3 | /api/health 需登录 | 免鉴权白名单缺失 | 登录/health/openapi 三路径免鉴权 |
| 4 | openapi paths 解析报错 | 遍历未编译正则（str 无 .pattern）+ 路径锚点处理错误 | 改遍历 _COMPILED + strip("^$") |
| 5 | 合同风险全量误报到期 | SQL 别名把 start_date 命名为 endDate | 别名改 end_date endDate |
| 6 | 新建员工 500 No item with that key | fire_event 查询漏 events 列 | SELECT 补 events |
| 7 | X-Hr-Key 免登录 401 | _user 未实现 Key 通道 | Key 有效即授予 auditor 只读身份 |
| 8 | CSV 导出断言失败 | Content-Disposition 文件名 URL 编码 | 测试改断言 attachment |
| 9 | 员工转正 500 bindings 3/2 | stage UPDATE 漏拼 no 参数 | args.append(no) |
| 10 | 核算后仍不能发放 | calc 未更新批次状态 | UPDATE status='已核算' |
| 11 | 内核允许试用期直跳已离职 / 草稿直跳已发放 | can_move 允许跨级前进，缺中间态校验 | 内核补 cur 中间态强校验（同口径修至 mock） |
| 12 | E2E 弹层选择器超时 | mask 才带 on 类 | "#dialog.on"→"#mask.on" |
| 13 | E2E 二次开浏览器报 asyncio 错 | 同进程二次 sync_playwright | 复用 browser.new_page() |
| 14 | 冒烟重复运行工号冲突 | 固定 EMP899 已建档 | 工号/周期/月份/日期全部时间戳唯一化 |
